# 今日热搜

「热搜省流版」网页：不用挨个打开微博、知乎、抖音，在一页里按分类看全今天在发生什么，点感兴趣的看详情、可收藏。

> 第一周 MVP · 演示数据版（非实时抓取）。项目文档见 `research.md`（需求研究）、`PRD.md`（产品需求）、`TECH_DESIGN.md`（技术设计）。

## 文件结构

```
vibe-coding-course/
├── index.html    # 首页：分类热搜列表 + 我的收藏
├── detail.html   # 详情页：单条热搜 6 个展示字段
├── style.css     # 两页共用样式
├── data.js       # 演示数据（3 分类 × 5 条，虚构内容）
└── main.js       # 逻辑：渲染列表 / 详情 / 收藏（localStorage）
```

## 本地运行（方式 A：本地服务器，推荐）

前提：电脑装有 Node.js（Day 1 已装；命令行敲 `node --version` 有版本号即可）。

1. 打开命令行（Git Bash / CMD / PowerShell 均可），进入本项目文件夹：

   ```
   cd C:\Users\HP\WorkBuddy\2026-09-16-22-23-56
   ```

2. 启动本地服务器（端口号 8000）：

   ```
   npx http-server -p 8000
   ```

   > `npx` 是 Node 自带的能力：临时借用 `http-server` 这个小工具跑一次，不算正式安装软件。第一次运行会联网下载并询问 `Ok to proceed?`，输入 `y` 回车即可。

3. 浏览器打开：

   ```
   http://localhost:8000
   ```

4. 停止服务器：在命令行窗口按 `Ctrl + C`。

## 备用方式（方式 B：直接双击）

双击 `index.html` 用浏览器直接打开——本 MVP 是纯静态页面，双击也能用，收藏等功能行为一致。但注意：**日常验收和交截图请用方式 A**，截图要求地址栏是 `localhost` 开头，双击打开的地址栏是 `file://` 开头，不满足要求。

## 验收要点（对照 PRD 第八节）

1. 首页 3 秒内出现 3 个分类、每类至少 3 条（标题 + 来源 + 🔥）；
2. 点任一条进详情页，6 个字段齐全，点「返回列表」回首页；
3. 详情页点「☆ 收藏」变「★ 已收藏」，回首页收藏区出现该条，**刷新页面收藏仍在**，再点可取消；
4. 「查看原文」新标签页打开演示数据里的链接。

## 注意

- 本仓库**没有任何密钥 / `.env`**（`.gitignore` 已隔离）；
- 收藏存在浏览器 localStorage：换浏览器 / 换电脑收藏不跟随，这是 MVP 的既定取舍。
